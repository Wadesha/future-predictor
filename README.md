# 未来预测 · 多层级交互式预测知识库

> 不是天气预报，不是调查报告。这里讨论的是：AI失业后消费会不会崩盘、你的存款会被通胀吃掉还是通缩变值、台海真的打起来你怎么办、极端灾难来了你能活几天。

## 这是什么？

一个让你**参与决策**的预测平台。每个话题不是给你一个结论就完事——而是让你选择自己的判断分支，然后**一层层往深挖**，直到你真正想清楚自己该怎么办。

## 你能看到什么？

### 4个尖锐话题，每个都能深挖3-4层

| 话题 | 第一层冲突 | 深挖到最后你会发现 |
|------|-----------|-------------------|
| **AI引发大规模失业后，消费会崩盘吗？** | 死亡螺旋 vs 新岗位接盘 vs 动荡期 | 如果你是中层白领，现在就该降负债 |
| **未来3年：物价飞涨还是通缩崩盘？** | 滞胀 vs 通缩 vs 恶性通胀 | 黄金还是比特币？中国会重演日本吗？ |
| **大规模战争离普通人有多远？** | 有限冲突 vs 台海热战 vs 新冷战 | 你的存款可能被冻结、该不该选边站 |
| **极端灾难明天发生，你能活几天？** | 断电72h崩溃 vs 供应链断裂 vs 社会秩序瓦解 | 4种净水方法你会几种？你的药断了怎么办？ |

### 首页交互功能

- **🔴 全球风险实时面板** — 6大风险指标一目了然，高危项会发光脉冲
- **🧪 生存准备指数测试** — 5个问题测出你能撑几天，答完立刻给你改进清单
- **每个话题的多层级深挖** — 选择分支后自动展开下一层子问题和推理链路
- **路径追踪** — 顶部实时显示你的探索路径：话题→分支→子问题→更深分支

## 怎么用？

1. **打开网站**，先看首页的风险面板，感受一下当前全球风险态势
2. **做生存测试**，5个问题，别骗自己——看看你的真实生存指数是多少
3. **选一个话题**深入探索——比如"AI失业后消费会崩盘吗"
4. **选择你认同的分支**（比如"死亡螺旋"），页面会自动展开下一层：
   - "谁会最先被冲击？" → "中层白领" → "消费崩盘的链式反应"
   - "房贷断供→房价暴跌→银行危机" 还是 "通缩螺旋" 还是 "社会动荡"
5. 每一层都有**推理链路**和**数据来源**，不是空口说白话
6. 你可以**补充自己的观察**，关联到具体分支
7. 去"我的"页面看你的**预测参与记录**

## 技术说明

- 纯静态网站，HTML + CSS + 原生 JS，无后端
- 用户数据存储在浏览器 LocalStorage，刷新不丢失
- 部署在 GitHub Pages，免费访问
- 数据全部是 JSON 文件，在 `data/topics/` 目录下
